GET STARTED

From source code to your first plot

PHARE is set up and analysed in Python, and runs in parallel with MPI. The steps below get you from a clone to a magnetic reconnection run and a plot. The documentation has every option.

Four steps

to validate

  1. Install the requirements

    Git, CMake, make or ninja, C++20 and Fortran compilers, MPI, parallel HDF5, and Python 3 with its development headers. SAMRAI, the AMR library, is downloaded and built for you unless you point CMake to an existing install.

  2. Build PHARE

    git clone https://github.com/PHAREHUB/PHARE
cd PHARE
python3 -m pip install -r requirements.txt
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release     # add -DSAMRAI_ROOT=/path/to/samrai to reuse an install
make -j

    Details and options: Building PHARE.

  3. Run a Harris current sheet

    cd ..    # back to the PHARE root
export PYTHONPATH=$PWD/build:$PWD/pyphare:$PWD
mpirun -n 4 python3 tests/functional/harris/harris_2d.py

    A 2D reconnection setup with automatic mesh refinement (200 × 100 cells, two levels, 10,000 time steps). At the end it saves plots of B, J, density and pressure in phare_outputs/harris_2d_plots/4/. This file is also a test of the code, so it deletes its raw outputs when it finishes.

  4. Make it your own run and plot it

    Copy the config() function of harris_2d.py into your own script and end it with Simulator(config()).run(): the outputs stay in phare_outputs/harris_2d. Then, in Python:

    from pyphare.pharesee.run import Run

run = Run("phare_outputs/harris_2d")
run.GetB(25.0).plot(qty="z", plot_patches=True, filename="bz.png")

    Every level and patch of the AMR hierarchy is read for you. How to write a run script: running from Python and simulation inputs. Reading outputs: getting data.
